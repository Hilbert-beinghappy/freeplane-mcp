# v0.2 qualification

Freeplane MCP v0.2 introduced revision-guarded atomic editing and one-step undo/redo. The qualified operation set covers node creation, text/details/notes, attributes, tags, icons, links, move/reorder, connectors, fold state, and confirmed deletion.

Every non-dry-run request is fully planned before mutation, executes inside one Freeplane transaction, and returns only after canonical readback. Failure injection must leave the pre-transaction snapshot unchanged. Idempotency receipts are private, payload-hashed, bridge-instance-bound, and contain no node content.

Run the historical gate with `npm run qualify:v0.2`. The authoritative evidence is `qualification/reports/v0.2-local.json`.
