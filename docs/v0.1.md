# v0.1 read-only real-time MCP

v0.1 exposes exactly six read-only MCP tools: `freeplane_status`, `freeplane_capabilities`, `freeplane_list_maps`, `freeplane_read`, `freeplane_search`, and `freeplane_changes`. No map-write tool is registered.

## Run

```bash
npm run qualify:v0.1
```

The qualifier builds the TypeScript server and Java add-on, launches a separate Freeplane process with a temporary `-U` profile and a synthetic 5,000-node map, exercises the real STDIO MCP surface, and removes only that spawned process and temporary profile.

## Qualified behavior

- Live bridge authority reads current unsaved state, selection, structured literal search, and revisioned changes.
- Reads are scope-bound, limited to 5,000 nodes per page, and page cursors are tied to authority instance, map, revision, and scope.
- Change cursors force full resync after journal expiry or bridge-instance change; short polling is capped at 750 ms.
- The journal retains at most 50,000 events and 64 MiB; qualification also measures the Freeplane process RSS delta.
- When the bridge is unavailable, only explicitly configured `.mm` files are exposed with `authority="file"` and `unsaved_visibility=false`.
- File parsing is read-only, UTF-8, bounded, no-follow, allowlist-constrained, and rejects DTD, entities, XInclude, malformed XML, excessive depth/text/attributes/size, symlinks, and non-regular files.
- Regex search and effective-style resolution remain unavailable until separately qualified.

## Local qualification evidence

The authoritative report is `qualification/reports/v0.1-local.json`. On the pinned local machine it records:

- status p95: 2.59 ms;
- 5,000-node read p95: 45.06 ms;
- maximum 5,000-node EDT snapshot slice: 82.47 ms;
- real Swing edit event visibility p95: 945.48 ms;
- 50,000-event journal RSS delta: 212,992 bytes;
- bridge reconnect: 228.13 ms.

These are local acceptance measurements, not performance guarantees for other machines.
