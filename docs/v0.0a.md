# v0.0A qualification gate

v0.0A freezes the exact local compatibility surface before any in-process Freeplane bridge or write tool exists.

## Run

```bash
npm run bootstrap
npm run qualify:v0.0a
```

`bootstrap` keeps `node_modules` and TypeScript build output on local APFS because this repository is on ExFAT. It refuses to replace real directories or unknown links.

The qualification command:

1. verifies Node 22 and exact locked MCP SDK/Zod versions;
2. compares ten Freeplane bundle artifacts with the frozen 1.13.3 hashes;
3. probes required public and internal classes with Freeplane's bundled Java 21 `javap`;
4. reproduces the menu inventory and audits the built-in MCP without reading its token;
5. starts an isolated Codex app-server with a temporary `CODEX_HOME`, creates an ephemeral thread, discovers both tools, and calls `freeplane_status` without starting a model turn;
6. runs the STDIO contract tests and rejects any non-JSON stdout.

Outputs:

- `qualification/reports/v0.0a-local.json`
- `qualification/capabilities/capabilities.json`

Only `runtime.status` and `runtime.capabilities` are enabled. All Freeplane map, edit, document, export, and GUI capabilities remain `needs_validation` until their later gates pass.
