# v0.4 qualification

Freeplane MCP v0.4 adds only the document and artifact operations that passed the isolated Freeplane 1.13.3 gate.

`freeplane_document` supports create, create from template, open, save, save as, close, and revert. Calls use content and file revisions. Existing targets, externally changed files, dirty close, and revert require a bound one-time confirmation.

`freeplane_export` supports map-scope PNG, PDF, SVG, and static HTML. Each export is written to a random sibling staging path, checked for its expected magic and structure, hashed, and atomically renamed. Existing artifacts are backed up before confirmed replacement.

Configured closed `.mm` files may receive ordinary-node `TEXT` updates through `freeplane_apply`. The route refuses files open in Freeplane, DTD/XXE input, symlinks, formulas, encrypted nodes, and non-text edits. It preserves all bytes outside the selected attributes, uses a native APFS clone for replacement, preserves xattrs, and stores original/candidate/manifest recovery evidence.

Node encryption remains unsupported because the MCP contract has no qualified secret-input channel.

Run the gate with:

```bash
npm run qualify:v0.4
```

The authoritative evidence is `qualification/reports/v0.4-local.json`: 26 checks cover the exact eleven-tool surface, lifecycle round trips and all close modes, conflict-bound confirmation, four artifact formats, overwrite backup, lexical unknown-XML/xattr preservation, open-file denial, hostile path/XML rejection, secure-input blocking, and preservation of pre-existing Freeplane processes.
