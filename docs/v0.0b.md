# v0.0B real-time and transaction qualification

v0.0B qualifies the version-locked Freeplane 1.13.3 add-on bridge before any map-write tool is exposed through MCP.

## Run

```bash
npm run qualify:v0.0b
```

The command builds the Java add-on with Freeplane's bundled JDK, starts a separate Freeplane process with a temporary user profile and fixture, and removes that isolated process and profile when the run finishes. The normal Freeplane profile, open user process, source fixture, and global installation are not modified.

## Hard gate

The qualification run verifies:

1. dynamic `127.0.0.1` binding, 256-bit bearer authentication, atomic discovery, `0700` runtime and `0600` discovery permissions, request IDs, Origin rejection, JSON content type, body limit, and main-thread dispatch;
2. a real Swing inline-editor change is readable without saving in under one second and appears in the event journal;
3. canonical map reads, literal search, revisions, cursor journal, listener capture, and snapshot reconciliation;
4. a 100-operation mixed transaction covering creation, text, notes, attributes, tags, icons, style, movement, folding, connectors, and deletion commits in under two seconds;
5. one Freeplane undo exactly restores the pre-transaction canonical snapshot and one redo exactly restores the committed snapshot;
6. injected failure after each of the 100 operations, plus a postcondition failure, restores transaction level and canonical snapshot equality with no `recovery_required` state;
7. a stale plan is rejected before writing, and the isolated fixture bytes remain unchanged because qualification never saves the map.

Freeplane's native delayed transaction settlement is used so deferred EDT actors remain inside the same compound undo or rollback unit. A commit or rollback is not reported until transaction level and canonical readback are verified; unverifiable settlement marks the map `recovery_required`.

## Outputs and boundary

- `qualification/reports/v0.0b-local.json`
- `qualification/capabilities/capabilities.json`
- add-on JAR and compiled classes under `~/Library/Caches/Freeplane-MCP/build/v0.0b`

Passing v0.0B verifies the local bridge and internal transaction capability for the pinned build. The capability remains blocked from MCP registration until the later read-only and edit-tool stages add the host-side lifecycle, schemas, confirmation, idempotency, and user-facing recovery flow.
