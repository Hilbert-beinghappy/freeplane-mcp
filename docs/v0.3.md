# v0.3 qualification

Freeplane MCP v0.3 adds only the knowledge-organization operations that passed the isolated Freeplane 1.13.3 gate.

Qualified atomic operations:

- safe native style and layout fields;
- left/right root placement and free-node positioning;
- content clones without subtree cloning;
- native summary groups;
- clouds and bookmarks;
- numeric arithmetic formulas without identifiers or scripts;
- reminders without scripts.

`freeplane_view` supports revision-guarded literal text filtering and clearing. Regex and executable conditions are not accepted. Conditional-style scripts, raw CSS, subtree clones, reminder scripts, document writes, exports, and GUI actions remain unavailable.

Run the gate with:

```bash
npm run qualify:v0.3
```

The authoritative local evidence is `qualification/reports/v0.3-local.json`. It reconstructs a synthetic 35-node/33-relation research map, verifies the five frozen H2 updates, injects a failure after every organization operation, checks native Swing layout overlap, and proves one undo/redo canonical equality. The qualifier uses an isolated `-U` profile and does not save its working map.
