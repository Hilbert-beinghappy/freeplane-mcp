# v1.0 local stable

v1.0 packages the qualified twelve-tool server as a repeatable local installation. It adds a manifest-owned installer/uninstaller, a dedicated Freeplane launcher, redacted `doctor` output, file and idempotency recovery commands, a compatibility matrix, an SPDX dependency inventory, and a final aggregate qualification report. It does not add another MCP tool.

## Install

Bootstrap and inspect the plan:

```bash
npm run bootstrap
npm run install:local
```

Apply only after reviewing the paths:

```bash
npm run install:local -- --apply
```

The default installation, runtime, and Freeplane user directory live under `~/Library/Application Support/Freeplane-MCP/` but do not overlap. Override them with `--prefix`, `--runtime-dir`, and `--freeplane-user-dir`. The default is a dedicated Freeplane profile; installing into a non-empty profile requires the explicit `--allow-existing-profile` flag.

Start the qualified Freeplane instance with `bin/freeplane-mcp-freeplane`. This launcher passes one exact project-owned startup script through Freeplane's native `-R<file>` option only for that process. It does not enable profile-wide unrestricted scripts, modify the built-in MCP setting, request Accessibility permission, or touch another Freeplane profile.

Configure Codex to run `bin/freeplane-mcp` with the installation prefix as its working directory. The server uses STDIO only. The Java bridge binds a dynamic port on `127.0.0.1`, authenticates with a private rotating token, and never listens publicly.

## Diagnose and uninstall

```bash
bin/freeplane-mcp-cli doctor
bin/freeplane-mcp-cli uninstall
bin/freeplane-mcp-cli uninstall --apply
```

`doctor` verifies the install manifest, exact Freeplane build, locked dependencies, helper signature, bridge identity, listener scope, capability manifest, and pending recovery state. It redacts home paths and omits tokens, requests, paths to maps, and map content.

Uninstall refuses any modified or unowned installation-prefix file. A successful uninstall atomically moves the add-on JAR and installation prefix out of service before deletion. It preserves the dedicated Freeplane profile's generated data plus the runtime backups and recovery ledger.

## Release boundary

This is a qualified local build, not a notarized or package-registry release. The repository has no project license selected. Formal redistribution remains blocked on license/legal review, project `LICENSE` selection, source headers, notarization, and an explicit release decision. No GitHub Release, deployment, upload, auto-update, or visibility change occurs in the v1.0 gate.
