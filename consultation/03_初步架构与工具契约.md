# 初步架构与工具契约

## 组件

```text
Codex
  ↕ STDIO MCP
TypeScript MCP server
  ├─ ↔ localhost token-auth bridge ↔ Freeplane Add-on ↔ in-memory unsaved maps
  ├─ ↔ safe .mm XML fallback ↔ saved maps
  └─ ↔ allow-listed action / later macOS AX fallback
```

桥接仅绑定`127.0.0.1`，使用动态端口、随机会话令牌和当前用户可读的发现文件。打开地图存在未保存状态时，以Freeplane内存状态为准；桥接不可用时显式降级，不能声称看到未保存变化。

## 组合式MCP工具

| 工具 | 核心作用 | 安全分类 |
|---|---|---|
| `get_freeplane_status` | 连接、版本、活动地图、revision、能力 | 只读 |
| `get_capabilities` | 用户目标到API/菜单/GUI/不可用路径 | 只读 |
| `list_maps` | 列出打开地图和稳定ID | 只读 |
| `read_map` | 按根节点、深度和字段读取地图 | 只读 |
| `read_selection` | 当前地图、选择和焦点 | 只读 |
| `search_nodes` | 文本/属性/标签/范围搜索 | 只读 |
| `get_changes_since` | 从revision补读变化 | 只读 |
| `create_map`、`open_map` | 建立或打开地图 | 写入/打开受控 |
| `save_map`、`close_map` | 保存或关闭；覆盖和未保存关闭需确认 | 条件破坏性 |
| `apply_operations` | 原子批量节点、样式、布局和关系操作 | 写入；删除需确认 |
| `invoke_action` | 仅允许列表内的菜单动作 | 按动作分类 |
| `export_map` | Freeplane实际支持的导出 | 覆盖需确认 |
| `undo`、`redo` | 撤销/重做一个事务 | 写入、可撤销 |

所有写入包含`map_id`与`expected_revision`。冲突时返回最新revision和差异摘要，不自动重试覆盖。`apply_operations`支持`dry_run`，成功后必须返回新revision、受影响节点和状态回读摘要。

## 文件安全

- 禁用XML外部实体和DTD网络访问。
- 解析后保留未知元素、属性、命名空间和插件数据。
- 写入顺序为：同目录临时文件→重新解析验证→原子替换。
- 失败时保留原文件；恢复副本不使用`_old`、`_new`等版本文件名，由事务目录或Git/快照管理。
