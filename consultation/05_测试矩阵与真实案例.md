# 测试矩阵与真实案例

## 自动化层级

| 层级 | 必测内容 |
|---|---|
| XML单元测试 | 中文、富文本、公式、未知扩展、损坏文件、XXE、原子写入 |
| MCP契约测试 | 工具元数据、Schema、注解、错误类型、稳定ID、确认策略 |
| 桥接集成测试 | 连接、认证、活动地图、选择、revision、事件日志、重连 |
| Freeplane批处理 | 使用`-R/-N/-S`创建、打开、保存和导出 |
| 冲突与恢复 | 旧revision、外部改写、崩溃、桥接重启、半失败事务 |
| 安全测试 | 删除、覆盖、加密、未保存关闭必须确认；路径越界拒绝 |
| 性能测试 | 5,000节点读取、100项批量修改、事件延迟 |
| 模型评测 | 直接/间接/后续/否定/高风险自然语言请求的工具选择与结果 |

## 真实研究导图验收

`real_example/移动App监管研究全景图.canvas`和高清PNG是现有真实成品的去敏副本。验收任务：

1. 从结构化内容在Freeplane中重建主要分区、节点和关系。
2. 找到H2节点并更新365日与730日结论。
3. 在指定父节点新增分支，设置状态颜色和说明。
4. 调整布局但保持逻辑关系。
5. 保存`.mm`，重新读取确认revision和内容。
6. 导出高清PNG/PDF并进行视觉检查。
7. 用一步撤销恢复整次修改，再用重做恢复。

## 合成全功能地图

另建固定fixture覆盖公式、提醒、过滤、克隆、标签、链接、连接线、云、摘要节点、演示和加密。该fixture用于能力覆盖，不混入用户研究数据。

## 证据标准

- 工具返回成功不是验收证据。
- 写入后必须读回Freeplane内存状态或重新打开文件。
- 导出类功能必须检查文件格式、尺寸、非空内容和至少一张视觉渲染。
- 不支持或环境失败保留为明确结果，不通过删除失败用例提高通过率。
